The mono footnote line that closes a section, under a hairline rule.

```jsx
<MetaRule note="Not your platform?">
  <ArrowLink href="/releases">Every file in v1.2.0</ArrowLink>
  <ArrowLink href="/docs/install" arrow="in">Full installation guide</ArrowLink>
</MetaRule>
```

Hairline top border, 11px uppercase mono, aside left and links right. This is
the page's footnote: escape hatches, alternate downloads, the long-form guide.
Nothing a first-time reader needs goes here. One per section at most.
