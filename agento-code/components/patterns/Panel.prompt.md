The default content container on marketing surfaces — eyebrow, Newsreader heading, muted body.

```jsx
<Panel eyebrow="Looks backward" title="Your history, made legible">
  <p>Agento never asks you to change how you work.</p>
</Panel>
<Panel variant="dashed" eyebrow="Looks forward" title="Agents that do the work">…</Panel>
<Panel size="card" eyebrow="01 · Chats" title="Talk to your agents">…</Panel>
```

In a two-up split, pair one solid panel with one dashed: solid is what exists,
dashed is what is coming.
