Reference tables in documentation — setting keys, platform matrices, environment variables.

```jsx
<DataTable head={['Setting', 'Default', 'What it does']} rows={[
  [<code>claude_executable_path</code>, '—', 'Explicit path to the CLI.'],
]} />
```

Values that are code go in a `<code>` element; the mono sizing is inherited from
`base.css`.
