The proof strip under a hero — small, checkable numbers, never percentages of nothing.

```jsx
<StatGrid items={[
  { n: '0', k: 'Bytes sent anywhere' },
  { n: '1', k: 'SQLite file, on your disk' },
  { n: '6', k: 'Integrations built in' },
  { n: '~60s', k: 'Install to first session' },
]} />
```

Four cells is the authored width. Withhold a number rather than show a weak one.
